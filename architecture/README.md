# Demo architecture notes

These notes describe the local compositions this project can prove.

They are not the UML model. The Architecture/UML project remains the source of truth for logical nodes. `uml-handoff.md` is the input for a later model update. This repository does not edit that model.

| Document | What it records |
| --- | --- |
| `logical-system.md` | Stable path from producer to database |
| `deployment-modes.md` | Docker now; Kubernetes and AWS later |
| `stages.md` | Experimental stages and their status |
| `networking.md` | Paths that exist, and the isolation those paths actually have |
| `acceptance.md` | Proofs for the current slice |
| `uml-handoff.md` | Logical node, local implementation, validation |
